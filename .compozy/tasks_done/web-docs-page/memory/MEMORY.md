Prose (task_04–06) and generated `_generated/*.md` (task_11) just drop `.md` files into the collection. Endpoints (task_07) read the same collection via `getCollection`/`render`. ## Shared Learnings
- Prose cross-link convention (task_04, for task_05/06): Markdown body links CANNOT use `assetPath`/`BASE_URL`. Use relative `../<slug>/` (e.g. `../concepts/`, `../governance/`) — base-agnostic, resolves under both `/` (local) and `/atelier` (Pages) thanks to the directory build format + trailing-slash nav. Targets that don't exist yet build fine locally but will 404 in a lychee link-check (task_08) until the sibling page lands.
- Approval/control-plane facts (verified in task_04, reusable for Governance task_06): default `approval_mode = "yolo"` (auto-approve, no prompt); set `"normal"` to be asked. Only write/command actions pause for approval, never reads. Approval chat item title "Action approval required" + `$ <cmd>` body (`src/app/chat/projection.rs:577`); approve with `y`/`yes`/`approve` (`src/tui/mod.rs:1178`). `fake` runtime's prompt control phrases are TEST scaffolding (`src/runtime/fake.rs`) — do not document them as product features.

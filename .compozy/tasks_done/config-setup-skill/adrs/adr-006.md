# ADR-006: Distribute via `npx skills add` (git); no npm-tarball bundle; hint via README + first-run nudge

## Status

Accepted

## Date

2026-06-15

## Context

ADR-002 chose the skills.sh consent rail. npm v12 (~July 2026) disables install scripts by default,
and atelier's binary npm package (`@matheusbbarni/atelier`) ships only `bin/` + `lib/`. Two audiences
need the skill: external host agents (any project), and atelier's **own** runtime for a user who
installed atelier globally — which means the skill must reach a personal root
(`~/.agents/skills/atelier-config-setup/`) that atelier discovers.

## Decision

- **Single install path:** `npx skills add MatheusBBarni/atelier atelier-config-setup`. Add
  `--global` to land in `~/.agents/skills` (atelier discovers it as a personal root); project scope
  lands in `.agents/skills`.
- **Do not bundle** the skill into `@matheusbbarni/atelier` (no `assemble.mjs`/`files` change, no
  lifecycle script) → the npm v12 caveat is moot.
- **Hint surfaces via** (a) the README install section and (b) an optional **one-line first-run
  nudge** from atelier when no `atelier-config-setup` skill is discovered in any root (e.g. "Tip:
  run `npx skills add MatheusBBarni/atelier atelier-config-setup` to configure atelier"). The nudge
  is read-only and never writes (PRD F7).

## Alternatives Considered

### Alternative 1: Bundle into the npm tarball + consented copy

- **Pros**: works without the external skills CLI.
- **Cons**: tarball weight; revisits the native installer the PRD deferred; any auto-copy hits npm v12.
- **Why rejected**: more moving parts for no V1 benefit.

### Alternative 2: README-only

- **Pros**: zero code.
- **Cons**: weak in-app discoverability for users already inside atelier.
- **Why rejected**: the first-run nudge is a cheap, high-value addition.

## Consequences

### Positive

- Zero packaging/lifecycle changes; faithful to the skills.sh pattern; serves both audiences.

### Negative

- Cross-agent install depends on the external `skills` CLI; the first-run nudge is a small atelier
  startup change.

### Risks

- `npx skills add` layout resolution scans `skills/atelier-config-setup/SKILL.md` **and** the mirrors
  → document name-targeted install; provide a manual-copy fallback in README.

## Implementation Notes

- First-run nudge lives in atelier startup, gated on "no `atelier-config-setup` discovered"; keep it
  suppressible (show once, or honor a `[ui]` toggle).

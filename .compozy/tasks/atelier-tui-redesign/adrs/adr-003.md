# ADR-003: Web Palette as Canonical Brand Source; Signature Spinner Deferred

## Status

Accepted

## Date

2026-06-11

## Context

ADR-001 proposed a copper + verdigris palette based on market gap analysis, before codebase research discovered that Atelier already ships a brand palette in `web/src/styles/global.css`: near-black ink (#060807), warm off-white text (#f2ead8), and green (#8cffb0) / amber (#ffb454) / cyan (#79e2e1) / red (#ff6f61) accents — a coherent craft-paper identity. Separately, PRD research identified the working indicator (Claude Code-style rotating gerunds) as a high-leverage brand surface, and clarification asked whether to build it in V1.

## Decision

1. **The web palette is the canonical brand source of truth.** The TUI theme tokens derive from the existing web CSS variables, so TUI screenshots and the website read as one product. This supersedes ADR-001's copper + verdigris proposal.
2. **The signature working indicator (rotating craft gerunds) is deferred to V2.** V1 restyles the existing spinner with theme colors only.
3. **Welcome tips are minimal**: a single `/help` hint, not a multi-item tips panel.

## Alternatives Considered

### Alternative 1: Copper + verdigris, migrate the web too

- **Description**: Adopt the idea-phase palette as the new brand and update the website to match.
- **Pros**: More distinctive in the agent-CLI category per market analysis.
- **Cons**: Adds web migration to a TUI-scoped effort; discards an existing, coherent identity; two surfaces drift during migration.
- **Why rejected**: Consistency with an existing brand beats novelty; the web palette's warm-paper character is equally unclaimed in the agent-CLI space.

### Alternative 2: Hybrid (web neutrals + copper accent)

- **Description**: Keep ink/text neutrals, introduce copper as the TUI signature accent.
- **Pros**: Some distinctiveness without full migration.
- **Cons**: TUI and web stop matching exactly where it is most visible — the accent color in screenshots.
- **Why rejected**: Splits the brand at its most recognizable element.

### Alternative 3: Craft-gerund spinner in V1

- **Description**: Rotating Atelier-themed verbs ("Sketching…", "Glazing…") + elapsed time + interrupt hint.
- **Pros**: Cheapest iconic-brand surface per market evidence (Claude Code's spinner).
- **Cons**: Adds verb curation, customization setting, and accessibility off-switch to the V1 timebox.
- **Why rejected**: User chose to defer; V2 stretch alongside the theme system.

## Consequences

### Positive

- Zero palette-design work in V1 — hex values already exist and are production-proven on the website.
- Brand consistency across every user touchpoint from day one.
- Smaller V1 scope (no spinner verb system, minimal tips).

### Negative

- Foregoes the copper + verdigris differentiation thesis from ADR-001's market analysis.
- The spinner remains generic in V1 — one fewer memorable surface in the launch GIF.

### Risks

- Web hex values were chosen for CSS rendering; they may need minor adjustment for terminal 256-color quantization — handled by the theme resolution layer (ADR-001).

## Implementation Notes

- TUI token mapping starts from: text=#f2ead8, muted=#b7ae9e, dim=#7e867a, panel/line tones, accents green=#8cffb0 / amber=#ffb454 / cyan=#79e2e1 / red=#ff6f61 on ink=#060807.
- Terminal backgrounds are not painted ink — the terminal's own background shows through; ink informs contrast checks only.
